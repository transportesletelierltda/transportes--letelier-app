TRANSPORTES LETELIER - PWA DEMO

Qué incluye:
- Login Administrador y Conductor
- Panel administrador
- Panel conductor
- Crear viajes
- Actualizar estados
- Registrar gastos
- Registrar documentos/fotos
- Resumen de ingresos y gastos
- Datos guardados en el teléfono mediante localStorage
- Modo PWA instalable desde Safari

IMPORTANTE:
Para instalarla en iPhone necesita estar publicada en una dirección HTTPS.
Luego se abre en Safari y se usa Compartir > Agregar a pantalla de inicio.

Esta primera versión es una demo local. No usa todavía una base de datos en la nube.
